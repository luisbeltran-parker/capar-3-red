Modelo OSI · Capa 3

Capa de Red

El "cerebro" del enrutamiento: lleva los datos de un origen a un destino a través de varias redes, eligiendo el mejor camino.

Capa 2 vs Capa 3

La capa 2 mueve datos dentro de una red local; la capa 3 los mueve entre redes.

Ficha rápida

PDU: paquete · Dirección: IP (lógica) · Dispositivos: router y switch capa 3 · Recibe segmentos y entrega a la capa 2.

Qué hace

Funciones principales

🏷️Direccionamiento lógico

IP de origen y destino. IPv4: 32 bits · IPv6: 128 bits.

🧭Enrutamiento

Decide el camino usando tablas de enrutamiento.

➡️Reenvío

El router manda el paquete por la interfaz de salida correcta.

✂️Fragmentación

Divide paquetes que superan el MTU y los rearma en destino.

🚦Congestión y QoS

Prioriza tráfico importante y evita saturar nodos.

📡Diagnóstico (ICMP)

Ping y traceroute: errores y pruebas.

Caso de estudio

Vehículos autónomos en una ciudad inteligente

Todo viaja en paquetes IP y la topología cambia en segundos. Un mensaje de frenada tardío puede causar un accidente.

Rutas cambiantes y pérdida de rutas

Alta velocidad, enlaces inestables: el siguiente salto desaparece.

Congestión en RSU

Muchos vehículos concentrados en un mismo cruce.

Latencia alta

Rutas largas o recálculo constante.

Handover

Al pasar de una RSU a otra cambia la IP o el punto de acceso.

Pérdida de paquetes

Enlaces intermitentes y saturación.

Cierre

Conclusión

La Capa 3 es el cerebro del enrutamiento: decide por dónde viajan los datos. En una ciudad inteligente su reto es adaptarse a una topología que cambia constantemente. Con protocolos dinámicos, enrutamiento geográfico, SDN, IPv6 y QoS, la información crítica llega rápido y de forma confiable.
Preguntas frecuentes · toca para ver la respuesta
¿Router vs switch?
Router: capa 3, usa IP y conecta redes distintas. Switch: capa 2, usa MAC dentro de una red.
¿IP vs MAC?
IP: lógica, cambia según la red. MAC: física, viene en la tarjeta de red.
¿Por qué no basta el enrutamiento estático?
La topología cambia todo el tiempo y no se puede configurar a mano.
¿Qué es el TTL?
Contador que evita que un paquete circule para siempre.
¿Qué es OSPF?
Protocolo de estado de enlace: usa Dijkstra para hallar el camino más corto.
¿Y si se pierde una ruta?
Se detecta el fallo, se recalcula y se usa una ruta alterna.
